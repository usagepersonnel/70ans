# Questions ouvertes

**Règles** (le tableau « où vit l'information » est dans `AGENTS.md`) :

- Ce fichier ne contient que des **questions ouvertes** : pas de réponses, pas d'historique.
- Quand une réponse arrive, on l'écrit dans le document qui fait foi, puis on **supprime** la question. L'historique git garde la trace. Réponse partielle : on réduit la question à ce qui reste ouvert.
- Les numéros sont **stables** : on ne renumérote pas et on ne réutilise pas un numéro. Des trous sont normaux, d'autres documents renvoient à ces numéros.
- Une question = 1 à 3 lignes, avec un renvoi vers le document qui donne le contexte.
